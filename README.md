# e^jπ

Calculadora CAS para el celular, hecha a la medida de un estudiante de ingeniería eléctrica
(fasores con ∠, ▸Rect/▸Polar, por unidad, trifásico, matrices, sistemas de ecuaciones).
Usa el mismo núcleo de cálculo que TNS Estudio en el PC (Python + SymPy), corriendo en el teléfono
con [Pyodide](https://pyodide.org) — no envía nada a ningún servidor.

**Instalar en iPhone:** abrir https://celisy33.github.io/ejpi en Safari → Compartir → *Agregar a inicio*.
La primera vez descarga ~24 MB; después funciona sin internet y se actualiza sola al abrirla con conexión.

Componentes de terceros: Pyodide (MPL-2.0), SymPy y mpmath (BSD), NumPy (BSD),
letras DejaVu (licencia libre, ver `fonts/LICENCIA-DejaVu.txt`).
